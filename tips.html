Getting started

Select Pinterest or Quick sample boards, set your timing, then press Start Drawing. Use the on‑screen controls (Prev / Pause / Next / End).

Tip: You can select multiple boards with Ctrl/Cmd‑click.

Pinterest setup

  • Click Connect to Pinterest, grant access, then Load my boards.
  • To switch accounts, use Log out → connect again.

Session timing

  • Standard: one duration for all images (e.g., 30s each).
  • Session limit: stop after N images, at a time limit, or run endless.

Class mode

  • Use presets (15m, 30m, 60m…) or build custom phases and breaks.
  • Drag rows by the ⋮⋮ handle to reorder.

Breaks & bells

  • Set bell times (seconds) like 600,300,120,60,30,10,0.
  • Choose Voice, Bell, or Voice and bell.

Image fit

Use Fit to Screen in the viewer to fill the viewport without cropping.

Troubleshooting

  • If images load slowly, try fewer boards or shorter durations.
  • If audio is muted, your browser may block autoplay—start the session and click Test bell.
  • If Pinterest boards don’t appear, click Log out and connect again.
